I choose the SimpleDiffuseAmbient shader so that I could attach a photo of my cat to the texture, then rotated the sphere so the texture faces the camera. Yes I just wanted to put my cat in.

I made the ShaderGraph to look like an ornament. I didn't have time to add other structures to the scene to place ornaments on.
